# 前言

部门组织了为期三天，在湖北恩施的团建，虽然有个人出行旅游的习惯，但是我大多的时间还是泡在各个地方的城市或者海边，鲜有这种直接进山蹚水

![恩施](/postImg/enshi-trip/DSC_3351.jpeg)


# 🚄 出发

出行来回的方案是坐高铁的卧铺，6月10的下午出发到高铁站，睡一晚第二天的早上到达湖北恩施，实话实说我从出生到现在也已经26年了…… 还没有坐过卧铺，也算是新奇的体验。 


高铁的卧铺是4人一个小房间，分上下卧，实话实说进去的时候比我想象中要小，但是也不是不可以接受，加上一连串的车厢房间都是同部门的同事，大家彼此熟悉，所以也不觉得局促或尴尬，互相串门也方便    

在基本没网的高铁上我们前端组的小伙伴聚在一块自然就是打牌消磨时间，已经做好玩到1、2点玩到困再各自休息的准备  

然而本人酒量不佳，在跟他们喝了一瓶4、5度的果酒后犯困直接躺在床上晕了过去😵 

再醒来已经是凌晨2点，看着周围睡着的小伙伴，有种梦回大学宿舍的感觉，翻了个身，准备接着好好休息，备足精神第二天跋山涉水

然而感觉到了高铁的摇晃，还有窗外时不时的爆闪，同事的呼噜，最后熬到了凌晨四点多才再次睡过去😵 

# 📅 Day 1

隔天早上到了恩施，在酒店附近简单吃了点东西后，一块乘坐大巴前往梭布垭石林，人数的问题我们分了两辆大巴，恩施的景点距离市区都是一个比较远的距离，
本想趁这段时间好好补个觉，但是大巴设备完善所赐，同事有了可以嗨歌的机会，刚出发没多久就开始，并且一路唱到了目的地

到地方后另一车的酒店同房间的朋友告诉我他们车所有人都在睡觉，补觉了一路，人与人的悲欢是真的不相通😭

那天的天气不好，是个阴天，加上本身石林的环境就比较幽暗，光线更是少之又少，虽然这样的环境下的石林别有一番风味，但是对于摄影佬来说真是噩梦💢  

一路上有看到个各种告示牌，还有导游的讲解，关于这些石头为什么这样命名，那些石头从哪个角度看会是怎样一个形状，一潭浅水为何会跟八卦的阴阳挂钩……
但是这些对我来说都太需要想象力了，想象力匮乏的我看了半天也看不出个所以来，我小小的眼睛里真的都是大大的疑惑

> 老大：你看这像不像 xxx，从这个角度看过去简直就是 xxx ！

> 啊？有吗

> 老大：这就是想象力！

![](/postImg/enshi-trip/0B78624C-FFC5-4CA0-8741-850C68375110_1_105_c.jpeg)

看来看去，拍来拍去，反而山中的花拍出来是我最满意的照片，虽然我不懂花，相对于周围干巴的石头，它在绝壁之间绽放其色彩，就会让我觉得那一片草木润泽，莺歌燕语

![](/postImg/enshi-trip/EFA06747-BF2D-4683-BDAD-10923773D08B_1_105_c.jpeg)

第一天的晚上自然就是聚餐的时间，惯例的喝酒，惯例的唱歌以及红包，但是之前参加的是技术部门的，这下直接跟整个大部门的人一块，熟悉了很多之前仅打过照面的同事，
还有跟一直线上对接的杭州的同学好好聊了下，也算是真真正正打过照面了  

脱身回到酒店洗漱准备躺下，被大哥老板们一个电话又 call 了出去，奔赴下半场夜宵跟酒局  

最后酒量不好的我自然是喝吐了🤮，歇了会感觉自己又在床上晕了过去😵

# 📸 Day 2

第二天一早又是长距离的大巴，上午要去屏山峡谷，然后下午则是去宣恩，前者又是爬山涉水，后者则是恩施的一个旅游县城  

去屏山峡谷之前看天气预报就看到是雨天，一番纠结后还是决定把相机带上，我的相机可不是娇生惯养的，后来也是庆幸自己这个决定，
顶着彻底淋湿的代价在屏山峡谷拍摄到了最上乘的“翡翠” 

![](/postImg/enshi-trip/DSC_3338.jpeg)

从大巴下来后先走一段上山路，比我想的要陡。有恐高的同事一直贴着左边走，我笑了他两句，随后自己也跟着往左靠。

![](/postImg/enshi-trip/567A6FF0-0E82-4E57-853D-63F34522132A_1_105_c.jpeg)

来都来了，爬山之后自然就是涉水，乘着船荡在河面，从一头划到了另一头，接着就是在溶洞之中摸黑往上， 中间也不乏有一些网红的打卡点，但是多少都得带点想象力，加上排队人满为患，遂放弃。最后乘大巴前往宣恩，虽然有雨衣，但是雨衣太闷加上爬上爬下，
身上还是湿了，好在恩施这个时候的气温比较高，感觉到了目的地后湿漉的头发都干的七七八八  

在白天的跋山涉水其实已经花费了大多的力气，下车后我们找了个烤鱼店吃饭（当然免不了又喝了点酒🍷，怎么还有人昨天没喝够啊我服了，喝的还是店家自己酿的四五十度的酒，抿了一口差点背了过去😷），尔后就沿着宣恩的河边散步，看着这里的夜景，以及等着晚点的乘船游宣恩的活动，
在游船的时候也近距离看到了打铁花

![](/postImg/enshi-trip/DSC_3466.jpeg)

回到酒店的时候已经挺晚了。坐了一天大巴，又爬了山、喝了酒，人已经很困。洗漱时看到老大在群里问要不要再出去吃点喝点，我又看了一眼第二天早上 8 点集合的通知，真庆幸微信没有已读的功能，
选择性地无视掉后躺在床上闭眼直接晕了过去 😵

# ⛰️ Day 3

行程上的最后一天，要去恩施大峡谷，本着前两天都是阴天，天气预报十分准确，我在起床的时候跟舍友信誓旦旦地说今天肯定又是个阴天，不会有什么太阳，忽悠着他把墨镜帽子放进了行李箱  

结果是个艳阳天，恩施啊恩施，真是把我当日本人整  

到了目的地后乘坐小火车，又转了缆车，把我们送到了半山腰上，我们从半山腰上开始爬，所以整体的路程其实还好，加上我跟小伙伴为了体验飞索的感觉，斥巨资 100RMB 又省了一段路  

就是真的晒啊……我连防晒都没涂，想到几个小时前信誓旦旦的自己，感觉真是个傻* 🤡  

恩施大峡谷其实给我感觉没有屏山峡谷好玩，屏山峡谷是山山水水，这恩施大峡谷就是山山山山山山山，连绵不绝的山，但是好在上去后视野非常开阔，用广角拍摄大景十分好看，
加上天气很好的缘故，随便拍拍都可以感觉到恢弘的气势

![](/postImg/enshi-trip/DSC_3552.jpeg) 

# 🚇 返程

从恩施大峡谷下来后就是返程前往高铁站的大巴，上了高铁后我们内部讨论（我跟另外两个小伙伴强烈提议！），已经连续喝了两三天了，真不能再喝了，遂改成了💰，
当然都是同事，自然也都是小💰  

一路从21点打到了炸金花，最后血亏7块钱结束战斗（后面又抢老板的红包抢回来了） 

今天没有喝，虽然高铁摇摇晃晃睡的也不舒服，但是有了之前的经验，我觉得我能够好好的睡个好觉了  

然而半夜拿起手机看到已经是凌晨一点半，跟另一位同事吐槽着对床轮着打呼噜的两人

最后果不其然，又是在差不多凌晨4点钟，实在撑不住晕了过去😵 

# 最后

难得这三天里面都没有看电脑，亦没有被工作所困扰，没有太多的焦虑，旅途虽然奔波，但也算是享受了这趟旅程，除了心情的放松，人生地图的开拓，还有与同事之间拉近了距离，已经是一趟很值得的旅程。
